ADMIN ACCESS

Create administrator

Create a confirmed account with the administrator role. Make sure the email belongs to the intended person. No invitation or password email is sent. Share the temporary password securely and ask the new administrator to reset it after signing in.

IMPORTANT

Credentials are not emailed

The password is sent only to Supabase over HTTPS and is never displayed or stored by this site after submission. Supabase stores passwords securely; they cannot be viewed later. Give the temporary password directly to the intended account holder using a secure channel.

Creating an admin grants broad access to manage listings, promotions, business applications, and reports. Only create accounts for people you trust.
